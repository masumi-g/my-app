# TechShare 要件定義書

## 1. 目的

TechShareは、技術に関する知識や記事を投稿・共有し、閲覧できるWebアプリケーションである。

## 2. 対象範囲

- 記事の一覧表示、詳細表示、投稿、編集、削除、検索を提供する。
- フロントエンドにReactとVite、記事データを扱うAPIサーバーにjson-serverを使用する。
- 記事本文はMarkdown形式で保存し、詳細画面と投稿・編集画面のプレビューで整形表示する。
- ログイン機能は画面操作確認用のデモ機能とする。実際の本人確認や認証を行うものではない。

## 3. 機能要件

| No. | 機能 | 要件 |
|---|---|---|
| FR-01 | 記事一覧 | 登録された記事をカード形式で一覧表示する。各カードから記事詳細へ移動できる。 |
| FR-02 | 記事詳細 | 記事のタイトル、投稿者、作成日、本文を表示する。本文はMarkdownとして整形する。 |
| FR-03 | 記事投稿 | タイトル、投稿者、本文を入力して記事を作成する。本文のMarkdownプレビューは入力と同時に更新する。投稿後は記事一覧へ移動し、新しい記事が一覧に表示される。 |
| FR-04 | 記事編集 | 既存記事のタイトルと本文をフォームに表示し、内容を更新する。更新後も作成日は変更しない。 |
| FR-05 | 記事削除 | 削除前に確認ダイアログを表示する。削除後は記事一覧へ移動し、削除した記事を一覧から除く。 |
| FR-06 | 記事検索 | タイトルと本文を検索対象とする。本文だけに含まれる語でも検索でき、大文字・小文字を区別しない。一致する記事がない場合は「記事が見つかりません」と表示する。 |

## 4. ログイン制御

- ログイン状態に応じて、ヘッダーの表示を切り替える。
- 編集・削除ボタンは、ログイン中の投稿者本人の記事にだけ表示する。
- 未ログインで`/create`を開いた場合は、トップページへ移動する。
- このログイン機能はデモ用であり、セキュリティ上の本人確認には使用しない。

## 5. 記事データ

| フィールド | 型 | 内容 |
|---|---|---|
| `id` | 文字列 | 記事を識別するID。json-serverが付与する。 |
| `title` | 文字列 | 記事タイトル。 |
| `content` | 文字列 | 記事本文。Markdown形式で保存する。 |
| `author` | 文字列 | 投稿者名。ログイン中のユーザー名を設定する。 |
| `createdAt` | 文字列 | 作成日時。ISO 8601形式で投稿時に設定し、編集時には変更しない。 |

## 6. APIエンドポイント

| HTTPメソッド | URL | 用途 |
|---|---|---|
| GET | `/articles` | 記事一覧を取得する。 |
| GET | `/articles/:id` | 指定した記事を取得する。 |
| POST | `/articles` | 新しい記事を作成する。 |
| PATCH | `/articles/:id` | 指定した記事の内容を更新する。 |
| DELETE | `/articles/:id` | 指定した記事を削除する。 |

記事検索は、取得した記事一覧をフロントエンド側で絞り込む。APIに検索専用エンドポイントは設けない。
